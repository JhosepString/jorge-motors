# Frontend — SPA

React + Vite + TypeScript. Se desarrolla en la Fase 3 (15/10 – 11/11/2026) a partir de los prototipos de `docs/prototipos/`.

## Vistas por rol

- **Administrador:** panel, productos y stock, registrar movimiento, alertas, reportes, proveedores y usuarios.
- **Mecánico:** registrar salida (3 pasos) y consultar stock (solo lectura).

Diseñado para PC (1440 px). Colores: azul #1A2B88 y naranja #F7A823. Tipografías: Poppins (títulos) e IBM Plex Sans (texto).
